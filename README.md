# Personalized GBM Drug Candidate Prioritization

This project develops a computational research pipeline for prioritizing drug candidates for glioblastoma (GBM) patient profiles.

The system will use:
- TCGA-GBM molecular data
- patient-specific genomic alterations
- drug-target information
- molecular features
- classical machine-learning methods

The output will be a ranked list of computationally prioritized drug candidates for research purposes.

This project is not intended to provide clinical treatment recommendations.
